## Behaviours to preserve

- Time range and harness come from the shared filters; every query uses `[start,end)` on `ts` (UTC) and the enabled-harness filter; All = union (rows per harness, summed in browser). Windows older than the 90-day snapshot horizon switch to the live `tool_calls` view (`server/clickhouse.ts:141-154`).
- Failure rate denominators exclude `unknown` outcome; `aborted` counts in the denominator but not in failed (aborted is queried in `tools.kpi` `V:179` but not shown). `unattributed` (task_id='') calls are queried but never shown.
