## Behaviours to preserve

- Window and filters: all queries filter `ts >= start AND ts < end` in UTC, enabled harnesses, and optional harness; All is summed per harness in the browser. Windows older than ~91 days use live views (`server.ts:377-394`).
- Cancellations are excluded from the error-rate denominator everywhere (KPI `rated_calls` and daily `rated_calls`, one definition). The "Model calls" KPI still counts cancelled calls (shown beside it), and daily TTFT medians include them.
- Codex semantics: calls are response streams; latency is the sampling step; retries come from `try_run_sampling_request` spans minus `run_sampling_request` steps; no throughput, no served model.
- Retries: three different routes per harness with a "Measured as" text in the table; Claude adds failed-attempt and exhausted counts in that text only.
- Hidden signal behaviour (stream disconnects ↔ retries KPI, throughput column, conformance panel and title); not-emitted harness is explained only in info popovers/chips.
- Sorting and limits: latency table calls desc (SQL LIMIT 30 harness×model, "Showing N of M" when cut); errors n desc LIMIT 25 (same notice); codex_sampling unlimited; error table "Last seen (UTC)" = first 16 chars of timestamp.
- Time zone: UTC day bucketing (`toDate(ts)`, `ts` is UTC typed); no Europe/London.
- Empty strings: chart empty text, three table empty messages (F12, F13, F18).
- Info popover contents and chip `title` text (see F14, F15); formulas live only in the registry-driven popover.
- `fmtSeconds` switches s → min → h (`format.ts:74-80`); null renders "—", never 0.
- No links out of this page.
