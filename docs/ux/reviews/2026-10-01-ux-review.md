# UX review (deep dive): Agent Introspection dashboard, 2026-10-01

A deep-dive review of every page against [`principles.md`](../principles.md) and [`DESIGN.md`](../DESIGN.md),
graded with the `ux-page` rubric ([`../rubrics/ux-page.yaml`](../rubrics/ux-page.yaml)) and compared with the
[2026-09-30 baseline](2026-09-30-ux-review.md). Beyond the baseline it covers accessibility, interaction states,
other window sizes, load times and the live data each page shows.

**Method.** The dashboard was built from the working tree on 2026-10-01, after the feature-audit defect fixes,
and served on port 4173 against live ClickHouse with the facts schema freshly installed. Each page was captured
in headless Chrome at the reference size, 2560 × 1440 (a 2560 × 1330 viewport), as a first screen and a full
page, with Last 7 days and All harnesses. Session was opened from a session link on Pipeline. The same run
measured every page in the browser: text below 12px, uppercase text, panel positions against the fold, chart
and table sizes, "Showing N of M" notices, links, info markers, native tooltips, load and API times. It also ran
axe-core (WCAG 2 A and AA plus best practice) and walked the first 30 keyboard stops. State captures cover the
info popover, chart readout, keyboard focus, loading, a failed query, an empty range, a 90-day single-harness
view, and widths of 1440, 1280 and 390. `colour_usage.py` and `contrast_check.py` ran on the source and the
tokens. One reviewer per page scored each criterion against its anchors, citing screenshots and `file:line`.
Totals come from `score_rubric.py` only. Data contradictions the reviewers reported were checked against live
ClickHouse before going into the backlog. Screenshots, measurements and score files are in git-ignored
`docs/ux/reviews/captures/2026-10-01/`; the baseline captures stay one level up. This document quotes no private
data.

**Scope.** Review and backlog only; no app code was changed.

**No-regression baseline.** The [feature audit](../feature-audit/README.md) lists every feature, signal and
calculation with a stable ID and a _New home_ column, and `dashboard/src/feature-audit.test.ts` fails if a
panel, figure or section title disappears. Every move below names the audit IDs it touches.

## Verdict

**The pages are steadier than on 2026-09-30, but the same shared presentation still holds ten of eleven pages at
Needs work and Session at Rework; Cache efficiency is the first page to reach Good (66.7).** Content now sits
beside the sidebar, panel definitions open instantly from an `i` popover, capped tables say "Showing N of M", and
the 2026-10-01 data fixes removed several contradictions. Together these lifted ten pages by 2.6 to 10.5 points.
What has not moved is shared: every page scores 1 of 3 on type and on charts (170px charts, 364 to 1,262
elements below 12px per page), and layout fit averages 1.1 because the extra width doesn't shorten any page. The
deep dive adds problems the baseline didn't measure. Every chart day is its own keyboard stop (124 axe
violations), capped tables can't be scrolled from the keyboard, and the error state has no retry beside it. Seven
pages link nowhere at the point of need, and five pages show contradictions in live data (three confirmed as
defects). Fixing the shared chart, type, keyboard and states layer first lifts every page at once; after that,
each page needs its comparison brought together on the first screen.

_Keyboard._ `focusOrder` (first 30 stops on Cache): 2 selects, 9 definition buttons, 2 "View as table" summaries, one `div` (the `#content` target), then 16 chart rects. Tab order in the DOM is skip link → 10 nav links → Refresh → selects → panels (`App.tsx:90-135`), so each load costs 13 stops before content.
Focusable chart rects per page (7-day window; every day between first and last row, including empty days, is a stop, `charts.tsx:271`): pipeline 8, cache 16, effort 29, tools 16, friction 14, guardrails 7, provider 16, recurrence 7, intent 4, interventions 7, session 0 (the node counts above). Charts are 1–2 stops worth of information (a trend) paid for with 4–29 stops each, and Escape does nothing in a chart.
_Focus visibility._ Buttons, links, inputs, selects, summaries get a 3px `--purple2` outline (`styles.css:751-757`; `focusOrder` 13 of 30 report `solid 3px`; `states/keyboard-focus.png` shows the ring on a session link). The popover is `role="tooltip"` and referenced by `aria-describedby` while `hidden`, which is acceptable.
_Reduced motion._ No `prefers-reduced-motion` rule in `styles.css`; the skeleton shimmer runs `infinite` at 1.2s (`:731`). Only motion in the app.
_Landmarks and headings._ `aside` holds the primary nav (`app-parts.tsx:52-57`); `header.topbar` is inside `main` so it is not a banner landmark (`:73`, `App.tsx:94-95`); two `nav` landmarks with the same name exist but only one is exposed at a time.
