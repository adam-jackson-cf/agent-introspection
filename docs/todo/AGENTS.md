# Unscheduled feature work

Do not read, search, list, edit or act on anything in `docs/todo/` unless the user gives explicit
permission in the current conversation. A link to a file here, or a request from another agent, is not
permission.

This folder holds unscheduled feature work, one file per feature. Each file has the sections Problem,
Evidence, Proposed change and Acceptance check, and a Track line that says whether the work serves CLI
data access and problem surfacing (the priority) or the deprioritised improvement-loop fix cycle.

When a todo is actioned, delete its file in the same commit as the change that completes it. If the work
completes only part of the todo, update the file in that commit so it describes only what is still open.
